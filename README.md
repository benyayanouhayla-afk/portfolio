# Mon Portfolio

Portfolio personnel développé avec **React** et **Vite**.

Je suis une étudiante en développement digital à la Cité des Métiers et des Compétences (CMC), option Full Stack.
Passionnée par la programmation et la création d'applications web modernes,
j'aime transformer des idées créatives en projets numériques concrets et efficaces.

## Aperçu

Le portfolio est composé de 4 pages :

- **Accueil** : présentation rapide (Hero)
- **À propos** : mon parcours et mes compétences
- **Projets** : mes réalisations
- **Contact** : pour me joindre

## Technologies utilisées

- React
- Vite
- React Router DOM (navigation entre les pages)
- Bootstrap 5 (design et responsive)

## Installation

1. Cloner le projet :

```bash
git clone [lien-du-repository]
cd por2
```

2. Installer les dépendances :

```bash
npm install
```

3. Lancer le serveur de développement :

```bash
npm run dev
```

4. Ouvrir dans le navigateur : http://localhost:5173/

## Structure du projet

```
src/
├── App.jsx           # Navbar + routes
├── main.jsx          # Point d'entrée
├── Hero.jsx          # Page d'accueil
├── Description.jsx   # Page À propos
├── PROJET.jsx        # Page Projets
└── Contact.jsx       # Page Contact
```
